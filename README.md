## 🎯 What is this?

Preparing for a certification exam can be exhausting, and most practice platforms are either too expensive or incredibly dull. **Security+ Prep Hub** is built by security enthusiasts, for security enthusiasts. 

It's a completely free, open-source web application packed with everything you need to study for the **SY0-701** exam. Whether you want to review terms with flashcards, target specific exam domains, or sit through a grueling 90-question timed exam simulator—this app has you covered!

## ✨ Features

- **⏱️ Authentic Exam Simulator**: Experience the real deal! A 90-minute timer for 90 randomly selected questions spanning all 5 exam domains.
- **📚 Domain-Specific Study Mode**: Target your weak spots. Focus exclusively on *General Security Concepts*, *Threats*, *Architecture*, *Operations*, or *Program Management*.
- **🎴 Interactive Flashcards**: Memorize complex acronyms and concepts (like NGFW, Zero Trust, and Air Gaps) with our flippable flashcards.
- **🧩 PBQ Simulations**: Practice Performance-Based Questions, a critical and challenging component of the actual CompTIA exam.
- **🌑 Sleek Dark Mode UI**: A premium, glassmorphism-inspired dark mode aesthetic designed to reduce eye strain during those late-night study sessions.

## 🚀 Getting Started

This project is fully open source. You can clone it, modify it, or run it locally to start studying immediately.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ishaantaneja/comptia-security-prep.git
   cd comptia-security-prep
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Start studying!** Open `http://localhost:5173` in your browser.
